### Этап 3 (OpenMP)

4. **«Лишь автоматическое распараллеливание» — это что?**
   - (а) директивы OpenMP над циклами (`#pragma omp parallel for`): мы только указываем параллельный цикл, а работу
     между потоками делит OpenMP — без ручного распределения по номерам потоков;
   - (б) распараллеливание самим компилятором вообще без директив (ключи `-ftree-parallelize-loops` в GCC,
     `/Qpar` в Visual Studio).

   **Ответ:** _(вписать)_
5. **Относительно чего считать ускорение?** Ускорение $S = T_1 / T_P$, где $T_P$ — время на $P$ потоках. Вопрос —
   что такое $T_1$:
   - (а) та же OpenMP-программа, запущенная на одном потоке;
   - (б) обычная последовательная программа этапа 2, без OpenMP.

   Программа с OpenMP даже на одном потоке обычно чуть медленнее последовательной (накладные расходы), поэтому
   по (а) ускорение выходит больше. Пример: этап 2 — 10 с, OpenMP на 1 потоке — 11 с, на 4 потоках — 3 с;
   по (а) $S = 11/3 \approx 3{,}7$, по (б) $S = 10/3 \approx 3{,}3$.

   **Ответ:** _(вписать)_
