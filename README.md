


ЛИТЕРАТУРА:

1. Учебники, в которых есть неявная разностная схема.
2. Учебник Джеймс Ортег, "Введение в параллельные и векторные методы решения линейных систем"
3. Головашкин, учебное пособие "Векторные алгоритмы вычислительной линейной алгебры", "Параллельные алгоритмы вычислительной линейной алгебры"

ЭТАПЫ:

1. На любом языке пишем решение задачи. Проверяем, что решение правильное. Результат: график зависимости погрешности от размерности.
2. Переписываем на компилируемом языке (Python, Matlab не подойдут), у которого можно убрать флаг компиляции. С, C++. Результат: график зависимости ускорения вычисления от размерности задачи.
3. Используем OpenMP. Используем лишь автоматическое распараллеливание. Результат: график зависимости ускорения.
4. Полноценная параллельная программа на MPI. Результат: график ускорения, зависимость ускорения от количества потоков.

Может изменять условие задачи прямо на сдаче. Например, изменять размерность матриц.

Задание: холецкий блочно через блочно скалярное произведение.
